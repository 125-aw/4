# 钢铁洪流 IRON TORRENT

俯视角科技像素坦克射击游戏，基于 HTML5 Canvas + 原生 JavaScript（ES6+），无任何外部依赖。

## 运行方式

直接用浏览器打开 `index.html` 即可运行。

如遇本地文件加载受限（部分浏览器对 `file://` 协议下加载 JS 有限制），推荐起一个本地静态服务器：

```bash
# 方式一：Python（任选一种）
python -m http.server 8000
# Python 2
python -m SimpleHTTPServer 8000

# 方式二：Node.js
npx http-server -p 8000
```

然后浏览器访问 `http://localhost:8000`。

## 操作说明

| 按键 | 功能 |
|------|------|
| W / A / S / D 或 方向键 | 移动 |
| 鼠标左键 / 空格 / J | 开火 |
| Shift | 加速（消耗能量） |
| 1 ~ 5 | 释放主动技能（护盾/速射/穿甲/地雷/清屏） |
| N | 跳过当前波次 |
| P | 暂停 / 继续 |
| M | 静音切换 |
| Esc | 返回菜单 |

移动端自动显示虚拟摇杆与开火按钮。

## 游戏机制

- **波次**：共 15 波，每 5 波出现一次 Boss。普通波清空所有敌人后进入下一波。
- **敌人四类型**：
  - 普通型（巡逻）、快速型（追踪）、装甲型（穿甲弹、血厚）、智能型（预判玩家走位、最具挑战），使用有限状态机 AI（巡逻 → 追踪 → 射击 → 躲避 → 智能预判）。
- **Boss 三阶段**：
  - 阶段 1（HP > 60%）：缓慢移动 + 主炮 + 地雷
  - 阶段 2（HP 30~60%）：加速、周期性护盾（护盾关闭时才能造成伤害）、散弹
  - 阶段 3（HP < 30%）：狂暴、全屏激光扫描（需躲避）、召唤小兵
- **道具**：⭐火力升级、🛡️护盾、❤️回血、💨加速、🏠基地加固、💥全屏清除、1UP 奖励生命；主动技能含护盾/速射/穿甲/地雷/清屏。击毁敌人有概率掉落，Boss 必掉。
- **障碍物**：砖墙（可摧毁）、钢墙（仅最高火力可破）、草丛（隐身）、水域（减速）。
- **基地保护**：地图下方为鹰巢基地，被摧毁即失败，需守卫！

## 调平衡

所有速度、血量、生成速率、道具时长等数值集中在 `js/config.js`，修改后刷新即可生效。

## 技术特性

- `requestAnimationFrame` + 增量时间（delta time）驱动，帧率无关
- 子弹与粒子使用对象池复用，减少 GC
- 离屏背景画布与滚动网格优化重绘
- 矩形（AABB）粗略碰撞 + 圆形精细碰撞
- Web Audio API 合成音效，无需音频资源文件
- localStorage 持久化关卡进度与设置（画质/音效/音量）
- 响应式触屏支持（虚拟摇杆 + 开火按钮）
